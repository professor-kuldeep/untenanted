# Untenanted Heart CMS V5.2 Features

## Publishing and content

- Posts with visual block editor
- Draft, review, scheduled, published and archived workflow
- Editor / SEO reviewer assignment and due dates
- Revision history and restore
- Editorial comments and audit history
- Editorial calendar / workflow views
- Homepage Builder
- Page Builder
- Collections / series
- Daily Reflection
- Media Library
- Navigation and site-design controls
- Trash / restore workflow

## SEO

- SEO Control Center
- Focus and secondary keywords
- SEO scoring
- SEO title / meta description
- Canonical URL
- Index / noindex and follow / nofollow
- Open Graph and X/Twitter metadata
- Article / BlogPosting / NewsArticle schema selection
- FAQ structured data
- Organization, WebSite, Breadcrumb and collection schema support
- Redirect Manager with 301/302/307/308
- Automatic 301 creation when supported content slugs change
- Taxonomy Manager for categories, emotions and tags
- XML sitemap, robots.txt, RSS feed and llms.txt
- Google verification field
- Keyword-conflict signal

## JMP-aligned analytics and operations

- First-party page-view tracking
- Anonymous visitor hashing
- Traffic sources / referrers
- UTM source, medium and campaign attribution
- Top pages, campaigns and devices
- 14-day visit trend
- CSV export
- Attribution stored with story, community and newsletter submissions
- Analytics consent banner and footer privacy preferences
- Optional GA4 client measurement after consent
- Optional server-side GA4 reporting
- Optional Google Search Console reporting
- System Health dashboard and `/api/health`
- Safe Backup, Super Admin Full Backup and merge restore

## Security

- Supabase authentication
- Member and admin password reset
- TOTP authenticator MFA for CMS accounts
- MFA challenge during admin login after enrollment
- Sign out other sessions
- Strong-password update interface
- Role-based admin navigation and server authorization
- Supabase RLS
- Server-only service credentials

- Reporting and moderation
- Pen-name support

- Confirmation flow
